Using LLMs for phenotyping

2026-10-14

Caveat emptor

Caveats

I will be showing you what you can do, not what you should do

Approaches shown today may be out of date by next week/month/year

Creating LLM tooling for phenotyping is easy, creating LLM tooling that improves the quality of research and provides a good user experience is hard

Choice of model undoubtedly matters. But not clear which model is best, by how much, for which task.

System prompts and user input can also have a dramatic impact on the results.

Closed-weight models often show performance drift, making validation even harder.

More caveats

Reliance on LLM tooling in OHDSI can increase barrier to entry, especially if tools are tied to specific providers (OpenAI, Antrhropic, etc)

And even more so if tools need access to other paid-for APIs (e.g. clinical resources)

Even more caveats

Low quality health research is prevalent

Reproducibility crisis in health research

Impact of increased LLM adoption? Double-checking and adding context vs unreproducible black box ….

Structured chat

Remember, even with the same model you can get different results!

chat_medgemma_new <- chat_ollama(
  model = "MedGemma:4b", 
  system_prompt = prompt
)
expected_age <- NULL
for (i in 1:10) {
  cloned_chat <- chat_medgemma_new$clone()
  res <- cloned_chat$chat_structured(
    "Summarise the clinical presentation and typical age at diagnosis of hypertension",
    type = type_object(
      clinical_summary = type_string(
        description = "Brief 1-sentence summary of the presentation."
      ),
      average_age_at_diagnosis = type_integer(
        description = "Estimated average age at diagnosis in years (positive integer between 1 and 100)."
      )
    )
  )
  
  expected_age[i] <- as.integer(res$average_age_at_diagnosis)
  
  cli::cli_inform(
    "Turn {i}: Expected age at clinical presentation of hypertension = {expected_age[i]}"
  )
}

Principles

Phenotyping tasks

A problem well stated is a problem half solved.

Nowadays, a problem well stated is a problem 95% solved.

Phenotyping tasks

Today we’re going to use LLMs for lower-stakes, human-in-the-loop, phenotyping tasks:

  • Drafting clinical descriptions
  • Reviewing concepts to include
  • Contextualising PhenotypeR results

Higher-risk topics we won’t cover (maybe for next year):

  • Searching for codes.

  • Creating cohort logic.

  • End-to-end, black box, phenotyping
